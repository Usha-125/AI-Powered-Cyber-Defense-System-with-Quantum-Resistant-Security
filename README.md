# 🔐 AI-Based Intrusion Detection System with Quantum-Safe Alert Encryption

## 📌 Overview

This project implements an **AI-powered Intrusion Detection System (IDS)** that classifies network activity as **Normal** or **Attack** using Machine Learning.
When an intrusion is detected, the system generates a detailed security alert and secures it using **quantum-safe encryption** techniques.

The project uniquely integrates:

* 🤖 **Artificial Intelligence** – for attack detection
* 🛡️ **Cybersecurity** – intrusion detection and alerting
* ⚛️ **Quantum Concepts** – future-ready, quantum-safe encryption

This makes the system **intelligent, secure, and future-proof**.

---

## 🎯 Objectives

* Detect malicious network activity using AI
* Simulate a real-world Intrusion Detection System
* Generate professional security alerts
* Protect alerts using quantum-resilient encryption
* Demonstrate the integration of AI + Cybersecurity + Quantum concepts

---

## 🔄 System Flow

```
Network Data (CSV)
        ↓
Data Preprocessing (Encoding)
        ↓
AI Model (Decision Tree Classifier)
        ↓
Prediction: Normal / Attack
        ↓
If Attack:
   → Generate Security Alert
   → Encrypt Alert (Quantum-Safe)
   → Decrypt for Authorized Admin
```

## ⚙️ Installation & Setup

### 1️⃣ Install Python

Download from: [https://www.python.org/downloads/](https://www.python.org/downloads/)
During installation, tick: **“Add Python to PATH”**

### 2️⃣ Install Visual Studio Code

Download from: [https://code.visualstudio.com/](https://code.visualstudio.com/)

Install the **Python extension** from VS Code Extensions.

### 3️⃣ Install Required Libraries

Open VS Code Terminal and run:

```bash
pip install pandas scikit-learn cryptography
```

## ▶️ How to Run the Project

1. Place all files in one folder:

   * `network_data.csv`
   * `final_system_clean.py`

2. Open the folder in VS Code.

3. Run the final system:

```bash
python final_system_clean.py
```

You will see:

* Incoming network activity
* AI decision (Normal / Attack)
* Generated security alert
* Encrypted alert (unreadable)
* Decrypted alert (for admin)
